# NPC 好感度

部分城镇 NPC 带有好感度系统。它与原版的 NPC 快乐度无关，是模组自己的一套数值。

## 基本情况

| 项目 | 内容 |
|---|---|
| 范围 | 0 到 100 |
| 保存 | 保存在**世界存档**里，多人联机时由服务器同步 |
| 每日限制 | 送礼、对话、治疗各算一次，游戏日 0 点重置 |
| 查看方式 | 与该 NPC 对话时在界面里显示 |

## 怎么提升

**送礼**（每天一次）。送对了加得多，送错了会掉。不同 NPC 的喜好不同，实测单个礼物在 **+10 / +5 / +3 / +1** 之间浮动，
送错礼物可能 **−3 到 −5**。

**对话**（每天一次）。每天第一次与该 NPC 对话可以 **+1**。

**治疗**。护士这类会给你治疗的 NPC，被治疗时会 **+1**。

## 高好感度会解锁什么

阈值大致分三档：

| 好感度 | 效果 |
|---|---|
| 70 以上 | 护士的治疗开始打折 |
| 80 以上 | 解锁额外的对话与互动选项 |
| 100 | 护士的治疗免费，并在对话结束时赋予耐力增益；树妖、向导、渔夫等也会开出各自的完整互动 |

## 最重要的一条：魔女途径的晋升仪式

**魔女途径序列六「欢愉魔女」**的晋升仪式要求：

> 护士、树妖、向导、渔夫四人中，**任意一位**好感度达到 100。

这也是目前唯一一处把好感度写进晋升条件的仪式。打算走魔女途径的话，
从序列七开始就可以每天给其中一位送礼，避免升到序列六时卡住。

## 目前有完整互动的 NPC

护士、树妖、向导、渔夫，以及老尼尔、阿罗德斯、克莱恩的日记等特殊角色。
其中老尼尔会赠送尚未踏入非凡之路者可饮用的序列九魔药。
