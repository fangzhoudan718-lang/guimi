# 新手入门

## 一、三条底层规则

**灵性**是与魔力完全分开的第二条资源条，所有非凡技能消耗的都是灵性，不是魔力。
灵性上限随序列晋升增长，所以高序列不只是伤害更高，能连放的技能也更多。

**晋升不可逆**。低序列不能直接饮用高序列魔药，必须按顺序喝；反过来，高序列饮用低序列魔药
也不会导致降级。也就是说点错途径不靠喝药补救，要么继续走下去，要么用重置手段。

**序列越高越强，但世界也在变强**。模组带有动态平衡：生命、防御这类固定加成会乘以
「动态世界等级」，该倍率从 0.1 起步，随原版与模组 Boss 进度提升。可在配置里关闭或改写。

## 二、怎么选途径

十条途径的定位：

| 途径 | 一句话定位 |
|---|---|
| 命运途径 | 幸运、概率与厄运，随机事件全部偏向你 |
| 魔女途径 | 魅惑、疾病、镜面与天灾 |
| 错误途径 | 偷取一切：物品、生命、意图、距离，直到命运与时间 |
| 愚者途径 | 占卜、秘偶、灵体与历史投影，控制与召唤见长 |
| 巨人途径 | 正面近战的防御与护盾堆叠，序列二开始能复活 |
| 红祭司途径 | 火焰与军团，高序列化身雷火巨人 |
| 月亮途径 | 药剂、驯兽、血液与月光，回复与召唤稳定 |
| 太阳途径 | 净化与光环，团队收益最高的支援型途径 |
| 门途径 | 空间与传送，从穿墙到空间破碎 |
| 黑皇帝途径 | 律令、贿赂、扭曲与熵，改写战场秩序 |

## 三、拿到第一瓶魔药

1. 在宝箱、钓鱼匣与 Boss 掉落中寻找**亵渎石板**，它记录着魔药配方。
2. 也可以直接找城镇 NPC **老尼尔**，他会赠送尚未踏入非凡之路者可饮用的序列九魔药。
3. 按配方收集材料，在制作台合成对应序列的魔药。
4. 饮用后即踏入该途径的序列九。

配方详见 [魔药与配方](Potions-and-Recipes.md)。

## 四、技能按键

所有非凡技能都在**控件设置**里绑定，默认键在十条途径之间大量复用。
同时修习多条途径时建议按需改键，完整列表见 [按键对照](Keybinds.md)。

## 五、卡住了怎么办

先看 [晋升仪式一览](Rituals.md)。多数卡关不是数值不够，而是仪式条件没满足：
仪式未完成时魔药是无法饮用的。
