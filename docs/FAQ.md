# 常见问题

**灵性和魔力有什么区别？**
灵性是模组新增的独立资源，所有非凡能力消耗的都是灵性。魔力只影响泰拉瑞亚原版的魔法武器。

**喝错途径的魔药能换回来吗？**
不能靠喝药补救。低序列无法饮用高序列魔药，高序列饮用低序列魔药也不会降级，
所以换途径需要重置手段，而不是靠灌药。

**魔药显示「仪式未完成」是什么意思？**
部分高序列在饮用前必须先完成晋升仪式。打开序列信息面板可以看到实时进度，
具体条件见 [晋升仪式一览](Rituals.md)。

**为什么技能按下去没反应？**
三种常见原因：灵性不足、技能还在冷却、当前序列还没解锁该技能。
另外面板上写的默认键有几处与控件注册值不一致，见 [按键对照](Keybinds.md)。

**「四叶草封印松动」提示里的学徒压制是什么意思？**
灰色四叶草类封印物的活性会随时间上涨。取下它活性会缓慢消退；
也可以消耗**学徒途径非凡特性**直接降低 45 点活性，这就是所谓的「用学徒压制」。

**多人联机里能力和进度会同步吗？**
技能状态、仪式进度与伤害判定都由服务器裁定并同步，客户端不会重复累加。
玩家之间的控制技能（例如放逐）需要双方都开启 PvP 才会生效。

**生命和防御加成好像没有面板写的那么高？**
固定数值加成会乘以动态世界等级。该倍率从 0.1 起步，随原版与模组 Boss 进度提升，
开启位格压制时还有阶段上限（肉山前 0.15 / 月总前 0.6 / 毕业后 1.0）。
可在模组配置里关闭或改写。

**这个模组超模吗？**
设计上偏强，建议搭配更高难度或开启动态平衡模式游玩。
